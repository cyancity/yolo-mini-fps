## 状态

- 已下载，并核对过格式和大小：GLB 文件头和长度字段一致，JPG 大小与 Poly Haven 接口给的字节数一致。
- 贴图已接进游戏（2026-11-12，加载和烘焙在 `src/gfx/photo_tex.js`，材质在 `src/gfx/materials.js`）。启动时和程序化贴图一起准备好，亮度对到原来的程序化贴图上；省内存档解码时缩到 512。加载失败或地址带 `?nophoto` 时退回程序化贴图。
  - `asphalt_04`：室外沥青地面（堆场、街道、卸货场），2.5 米一张。底色和法线来自照片，积水用的高度由明度和环境光遮蔽凑出来；湿度、积水、倒影、标线照旧。
  - `concrete_wall_008`：所有混凝土材质的竖面和朝下的面（月台立面、勒脚、围墙、隔离墩），3.6 米一张。
  - `concrete_floor_damaged_01`：所有混凝土材质朝上的面（仓库地面、月台面、楼梯踏面），3 米一张，同一张图换位置和朝向采两次混在一起。
  - `container_side`：只取细节。照片自带的波纹和箱体几何的波纹间距对不上，所以减掉波纹，把剩下的划痕、蹭脏、凹坑叠在所有涂装金属上（集装箱、仓库外墙板、卷帘门、车），3.1 米一张；漆色、锈迹、喷字不变。
  - `corrugated_iron_02`：没有用上，也不加载。场景里的波纹板都是带真实起伏的几何体（间距 0.075 到 0.276 米，按板宽取整），照片里的细波纹从材质这一层对不上；也没有适合直接贴它的平面。
- 动作还没有接进游戏。动作只在程序化动作显得僵硬时才换上，需要先把敌人骨架对到这套动作的骨骼上；这次没有下载它的骨架和基础模型（`skeleton.glb`、`model.glb`），要用时另行确认。

## 使用约定

- 法线图是 OpenGL 约定（`nor_gl`）。
- `arm` 图的 R、G、B 三个通道依次是环境光遮蔽、粗糙度、金属度。
- 下载脚本不放在这个目录里。
